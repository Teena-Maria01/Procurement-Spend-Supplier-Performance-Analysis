This project presents an interactive Procurement Analytics Dashboard built in Power BI to analyze $36M in annual technology contract spend across 24 suppliers and 6 procurement categories in Australia.
The objective was to transform raw procurement data into executive-level insights that support:

Spend transparency
Supplier performance monitoring
Operational risk assessment
Vendor concentration analysis
Strategic sourcing decisions

The dashboard is designed for executive stakeholders seeking real-time visibility into financial exposure, supplier reliability, and procurement risk.

Key Insights

$36M total contract value across technology suppliers
Software Licensing identified as highest spend category ($9.3M)
Microsoft Australia identified as top supplier ($4.2M)
92.7% average SLA compliance across vendors
111 total operational incidents monitored
$1.7M financial exposure linked to high-risk suppliers
Top 5 suppliers account for 40.8% of total spend, indicating vendor concentration risk

These insights enable procurement leadership to assess financial exposure and operational resilience.
